# 이중슬릿 양자통신 시뮬레이션

Alice가 광자를 전송하고 Bob이 이중슬릿 간섭무늬와 도착 광자 수를 관찰하는 연구용 시뮬레이션입니다. 한 구간은 광자 1,000개로 구성됩니다.

## 파일

- `interference_visualizer.html`: 브라우저에서 여는 한 구간 시각화. 자연 손실률(0–10%), Eve의 광자 탈취 여부 및 탈취 수(0–100개)를 바꿀 수 있습니다.
- `false_positive_sim.py`: 도청자가 없는 경우의 위치 히스토그램에서 total variation(TV) 거리의 분포와 분위수 임계값을 계산하는 별도 탐색 스크립트입니다.

## 실행

`interference_visualizer.html`을 웹 브라우저로 열고 **한 구간 생성**을 누릅니다. 외부 라이브러리는 필요하지 않습니다.

Python 스크립트도 표준 라이브러리만 사용합니다.

```bash
python false_positive_sim.py --photons 1000 --trials 10000 --alpha 0.01
```

## 현재 모델의 범위

시각화에서 광자 수 기준 전체 오차율은 `(1000 - Bob 도착량) / 1000`입니다. Eve는 광자를 빼돌리고 재전송하지 않는다고 가정합니다. 표시되는 Eve 판별 정확도는 현재 코드의 탐색적 몬테카를로 추정이며 실제 공격자의 성공 확률이나 보안 증명을 뜻하지 않습니다. 두 파일은 서로 다른 탐색 단계의 코드입니다. Python의 TV 임계값을 시각화의 최종 도청 판정 기준으로 적용한 상태는 아닙니다.

자연 손실과 Eve 탈취에 의한 손실은 Bob의 총 도착 수만으로는 원인을 구별할 수 없습니다. 실제 장치 평가에는 검출기 효율, 잡음, 동기화, 공격 모델 및 독립적인 보안 분석이 더 필요합니다.
